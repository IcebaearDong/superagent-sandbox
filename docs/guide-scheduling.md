# Scheduling

harnessctl keeps the state directory, the resolved profile and the job queue in one place.
This page describes what to expect from a clean installation.

## Overview

Diagnostics go to standard error so that the normal output stays clean. A successful run prints nothing beyond the final line. After a change, restart the process so that the new value is read. The change is commited on a branch, never on the default branch.

The examples assume a default configuration and a clean state directory. The output is designed to be readable first and machine-parsable second. Use the verbose flag when you need to see why a step was skipped. The log is rotated at the begining of each run.
