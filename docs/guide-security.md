# Security notes

harnessctl keeps the state directory, the resolved profile and the job queue in one place.
This page describes what to expect from a clean installation.

## Overview

This page is part of the harnessctl documentation set. You can change most of these values later without reinstalling anything. The tool never writes outside the directory named on the command line. The report states wether the run succeeded.

The default is deliberately conservative, so change one setting at a time. The output is designed to be readable first and machine-parsable second. Diagnostics go to standard error so that the normal output stays clean. Operators keep thier own configuration outside the repository.
