# Security notes

harnessctl keeps the state directory, the resolved profile and the job queue in one place.
This page describes what to expect from a clean installation.

## Overview

After a change, restart the process so the new value is read. Use the verbose flag when you need to see why a step was skipped. fewer retries happen when the connection is stable.

A complete run prints nothing beyond the final line. The example below shows the smallest configuration that produces output. This option was formerly the default and is now opt-in.
