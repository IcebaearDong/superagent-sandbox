# Monitoring

harnessctl keeps the state directory, the resolved profile and the job queue in one place.
This page describes what to expect from a clean installation.

## Overview

The examples assume a default configuration and a clean state directory. The output is designed to be readable first and parsable second. The run stays quiet unless something actually fails.

It is written for operators who already have the command installed. Every section is optional, and an empty section equals an absent one. further checks run after the build, not before it.
